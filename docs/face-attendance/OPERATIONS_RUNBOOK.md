# Panduan Operasional Petugas Presensi Wajah (Operations Runbook)

## 1. Persiapan Sesi Pengajian
1. Masuk ke aplikasi PPG Magetan Timur menggunakan akun pengajar atau admin kelompok.
2. Buka menu **Presensi Kehadiran** atau klik langsung **Presensi Wajah (Magtim)** pada sidebar.
3. Pastikan **Kelompok** dan **Jenis Pengajian** (misal: *Sambung Kelompok*, *Pengajian Caberawit*) sudah dipilih sesuai kegiatan yang berlangsung.

## 2. Cara Mendaftarkan Wajah Santri (Enrollment)
1. Buka tab **Data Face ID** atau klik tombol ikon wajah di samping nama santri pada tab **Input Manual**.
2. Arahkan kamera ke wajah santri.
3. Pastikan santri berada di dalam lingkaran/oval panduan hingga muncul indikator hijau `Posisi Sesuai ✓`.
4. Klik tombol **Daftarkan Wajah Sekarang**.

## 3. Menjalankan Pemindaian Presensi Wajah
1. Buka tab **Scan Wajah**.
2. Klik tombol **Mulai Kamera Scan**.
3. Minta santri/jamaah berdiri menghadap kamera bergantian.
4. Saat wajah cocok, sistem akan:
   - Membunyikan nada konfirmasi (beep).
   - Menampilkan kartu nama, foto, dan persentase kecocokan.
   - Otomatis mencatat status santri menjadi **Hadir** untuk sesi tersebut.
5. Jika santri sudah pernah absen sebelumnya di sesi yang sama, sistem akan memberitahukan **Sudah Tercatat**.

## 4. Prosedur Fallback Jika Gagal Scan
Jika wajah santri tidak dikenali karena pencahayaan ekstrem atau belum terdaftar:
- Petugas dapat langsung mengklik tombol **Hadirkan** pada panel daftar santri di sebelah kanan tanpa perlu mematikan kamera.
- Atau berpindah ke tab **Input Manual** untuk mencatat kehadiran secara konvensional.
